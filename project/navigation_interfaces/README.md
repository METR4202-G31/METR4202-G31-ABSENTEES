# Navigation Interfaces

Shared ROS 2 interfaces for navigation and autonomous exploration.

This package contains the custom actions and messages used to communicate between
the Navigation Supervisor, Frontier Explorer, and other navigation related modules.

## Interfaces

The package currently defines:

```text
navigation_interfaces/
├── action/
│   └── ManagedNavigate.action
└── msg/
    ├── FailedRegion.msg
    └── FailedRegionArray.msg
```

## ManagedNavigate Action

`ManagedNavigate` provides the common navigation interface used by higher level
modules to request supervised navigation.

```text
navigation_interfaces/action/ManagedNavigate
```

### Goal

```text
geometry_msgs/PoseStamped target_pose
```

`target_pose` contains the requested robot destination.

The Navigation Supervisor currently expects navigation goals to be expressed in
the `map` frame.

### Result

```text
uint8 result_code
string message
bool failed_region_recorded
```

The available result codes are:

| Code | Result | Description |
|---:|---|---|
| 0 | `SUCCEEDED` | Navigation completed successfully |
| 1 | `BLACKLISTED` | Goal was rejected by a navigation policy |
| 2 | `PLANNING_FAILED` | A valid path could not be generated |
| 3 | `NAVIGATION_FAILED` | Navigation failed during execution |
| 4 | `STUCK` | Robot failed to make sufficient progress |
| 5 | `CANCELED` | Navigation was canceled |
| 6 | `INVALID_GOAL` | Supplied goal was invalid |
| 7 | `INTERNAL_ERROR` | Internal navigation supervision error |

`message` provides a description of the result.

`failed_region_recorded` indicates whether the failed navigation attempt caused
a failed region to be recorded.

Not every defined result is currently generated by the Navigation Supervisor.
Some result codes are retained for future failure classification and use by other
navigation modules.

### Feedback

The action also defines:

```text
uint8 state
float32 distance_remaining
builtin_interfaces/Duration navigation_time
uint16 recovery_count
```

with the following navigation states:

| Code | State |
|---:|---|
| 0 | `CHECKING_GOAL` |
| 1 | `PLANNING` |
| 2 | `NAVIGATING` |
| 3 | `CANCELING` |

These fields allow navigation progress and recovery behaviour to be reported to
the requesting module.

ManagedNavigate feedback is defined by the interface but is not currently
published by the Navigation Supervisor.

## FailedRegion Message

`FailedRegion` describes an area associated with one or more failed navigation
attempts.

```text
navigation_interfaces/msg/FailedRegion
```

The message contains:

```text
uint32 region_id

geometry_msgs/Point center
float32 radius

uint32 failure_count
uint8 last_failure_reason

builtin_interfaces/Time first_failure_time
builtin_interfaces/Time last_failure_time
```

The available failure reasons are:

| Code | Failure reason |
|---:|---|
| 0 | `PLANNING_FAILED` |
| 1 | `NAVIGATION_FAILED` |
| 2 | `STUCK` |
| 3 | `NAVIGATION_TIMEOUT` |

`region_id` uniquely identifies the region.

`center` and `radius` define the affected area.

`failure_count` records how many failures have been associated with the region.

The two timestamps record when the first and most recent failures occurred.

## FailedRegionArray Message

`FailedRegionArray` contains the current collection of failed regions.

```text
navigation_interfaces/msg/FailedRegionArray
```

The message contains:

```text
std_msgs/Header header
navigation_interfaces/FailedRegion[] regions
```

The `header` identifies the reference frame and timestamp of the published
failed-region data.

The Navigation Supervisor currently publishes this message on:

```text
/failed_regions
```

## Build

From the project workspace:

```bash
source /opt/ros/humble/setup.bash

colcon build \
    --packages-select navigation_interfaces

source install/setup.bash
```

## Inspect Interfaces

After building and sourcing the workspace, the generated interfaces can be
inspected with:

```bash
ros2 interface show navigation_interfaces/action/ManagedNavigate
```

```bash
ros2 interface show navigation_interfaces/msg/FailedRegion
```

```bash
ros2 interface show navigation_interfaces/msg/FailedRegionArray
```

The available interfaces can also be listed with:

```bash
ros2 interface list | grep navigation_interfaces
```
